# 伶仃护航——面向受限水域的 AIS-视觉融合船舶碰撞风险预警系统

**（项目书 · 初稿）**

> 说明：本文档为参赛项目书初稿，其中【】标注处需团队补充真实数据、出处或成员信息。项目名称可后续调整。

---

## 一、项目概述

### 1.1 一句话定位

面向珠江口伶仃航道等受限水域，针对"大船有 AIS、小渔船无 AIS"的感知盲区，构建一套**AIS-视觉融合的船舶碰撞风险预警系统**——在碰撞发生前实时评估风险，能避则给出避让建议，实在无法避免时给出"损失最小"的操纵参考。

### 1.2 核心问题

伶仃航道是广州港、深圳港船舶进出珠江口的主航道，狭窄、水深受限、且航道一侧毗邻港珠澳大桥水域。航道上大型商船密集，同时大量小型渔船在航道附近作业、横穿。多数渔船**未安装或未开启 AIS 设备**，对商船而言处于"不可见"状态，极易酿成碰撞事故。

现有船舶避碰手段的痛点：

| 手段 | 局限 |
|------|------|
| 船员目视瞭望 | 夜间、雾天、大浪、疲劳时可靠性差 |
| AIS（自动识别系统） | 只能看到"有 AIS 的船"，对无 AIS 渔船完全盲区 |
| 雷达/电子海图 | 能发现目标，但无法识别目标属性、也依赖人工判断 |
| 现有碰撞预警 | 多为直线外推的 CPA 计算，对渔船突转、停船等机动反应迟钝 |

### 1.3 解决方案

以**船上视角**（系统安装在商船上）构建边缘计算预警终端：

- **看得见**：多摄像头（可见光+红外）感知海面，检测无 AIS 的小型渔船；
- **猜得准**：融合 AIS 与视觉目标，跟踪并预测渔船机动轨迹；
- **评得准**：基于分扇区船舶领域与碰撞危险度，实时划分绿/黄/红风险分区；
- **损失小**：可避则给出避让建议；碰撞不可避免时给出损失最小化操纵参考（减速、选撞击角、防搁浅）。

系统**只告警、只建议，不接管船舶的自动舵与主机**，由驾驶员决策执行。

## 二、项目背景与意义

### 2.1 场景背景

伶仃航道（珠江口）具有典型的受限水域特征：**航道窄、水深受限、船舶密度大、渔船活动频繁、近岸且有桥梁水域**。大型集装箱船、散货船在航道内机动能力受限，一旦与横穿的小渔船形成紧迫局面，往往"避让空间不足"。

【此处补充：珠江口/伶仃航道近年商船与渔船碰撞事故的统计数据与出处，海事局事故通报等】

### 2.2 技术背景与本项目的针对性

1. **AIS 盲区问题**：AIS 只能覆盖"配合"的船舶。无 AIS 渔船是海上碰撞的高危来源，传统 AIS 预警系统对此无能为力。本项目以视觉感知补全这一盲区。
2. **渔船机动不可预测**：渔船会突然停船收网、急转、加速躲避。基于"航向航速不变"的直线外推（CPA/DCPA/TCPA）对这类机动目标失效，需要学习式的轨迹预测。
3. **避碰决策缺"兜底"**：绝大多数避碰研究假设"一定避得开"。本项目明确处理"避不开"的情形，给出损失最小化决策，填补这一空白。

### 2.3 意义

- **安全价值**：降低受限水域商船-渔船碰撞事故率，保护渔船船员生命安全，减少船舶破损与水域污染风险。
- **产业价值**：可作为商船驾驶辅助终端、内河/沿海 VTS 辅助模块推广。
- **研究价值**：打通"多源融合检测 → 机动预测 → 风险分区 → 损失最小化决策"的完整链条。

## 三、项目技术方案

### 3.1 系统总体架构

系统部署于商船（本船），由四部分组成：数据接入、边缘计算、风险决策、人机交互。

```
┌─────────────────────────────────────────────────────────────┐
│ 数据接入层                                                      │
│  ① AIS接收机：本船船位/航向/航速、人工录入吃水、周边大船轨迹   │
│  ② ECDIS电子海图：航道疏浚槽、浅滩水深边界（搁浅约束）          │
│  ③ 新增硬件：海面多摄像头 + 红外传感器 → 边缘计算盒子           │
├─────────────────────────────────────────────────────────────┤
│ 边缘算法层（核心）                                              │
│  ④ 多源融合：可见光+红外融合；视觉目标与AIS目标关联（识别无AIS） │
│  ⑤ 检测+跟踪：检测渔船 → 多目标跟踪 → 估计渔船航向航速           │
│  ⑥ 轨迹预测：渔船机动轨迹学习式预测（含不确定性）                │
│  ⑦ 风险评估：分扇区船舶领域 + 碰撞危险度CRI → 绿/黄/红分区       │
│  ⑧ 避碰决策：可避→避让建议；不可避→损失最小化操纵参考            │
├─────────────────────────────────────────────────────────────┤
│ 输出层                                                        │
│  ⑨ 告警+辅助建议 → 驾驶台显示器（不接管自动舵/主机）            │
│  ⑩ （可选）告警事件上传岸基VTS，非实时主链路                    │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 感知层：多传感器检测与融合

- **可见光 + 红外融合**：白天靠可见光，夜间/雾天/逆光靠红外，保证全天候检测能力。
- **小目标检测**：渔船在海面成像面积小，需针对性优化的小目标检测网络（基于公开海事图像数据集训练，如 SeaShips、新加坡海事数据集等）。
- **多源融合的两层含义**：
  1. 传感器级融合：可见光与红外检测结果融合，得到更稳健的目标；
  2. 目标级关联：视觉目标与 AIS 目标匹配，**匹配不上的即判定为"无 AIS 目标"**。

### 3.3 跟踪与数据关联

- **多目标跟踪（MOT）**：将连续帧的检测关联成轨迹，估计每个目标的航向、航速——这是计算 DCPA/TCPA 的前提。
- **数据关联**：将视觉轨迹与 AIS 轨迹进行时空匹配。成功匹配 → 该目标有 AIS；匹配失败 → 该目标为无 AIS 渔船，进入"重点风险"处理流程。

### 3.4 轨迹预测

传统方法（航向航速不变直线外推）对渔船突转、停船、急加速失效。本项目引入学习式预测：

- 输入：目标历史轨迹序列（位置、航向、航速）。
- 模型：LSTM / Transformer 等序列模型，学习渔船机动模式。
- 输出：未来一段时间的位置概率分布（**含不确定性**），而非单条确定性轨迹。
- 意义：用预测的不确定性来衡量风险，比单点预测更稳健，尤其适合"渔船会突然转向"的场景。

### 3.5 碰撞风险评估：分扇区船舶领域 + 碰撞危险度

本模块对每个目标实时评估碰撞风险，核心是"船舶领域（Ship Domain）+ 碰撞危险度（CRI）"两类经典方法的结合。

**（1）风险因子与会遇几何**

对每个目标提取标准运动学风险因子，并计算会遇参数（设两船相对速度向量与连线夹角为 α）：

- 相对距离 `D`、相对速度 `Vr`、相对方位 `θ`（目标相对本船的舷角）、船速比 `K = vt/vo`；
- 最近会遇距离与时间：

```
DCPA = D * sin(α)          （最近会遇距离）
TCPA = D * cos(α) / Vr     （到最近会遇点时间，TCPA>0 表示正在逼近）
```

**（2）船舶领域（Ship Domain）——风险分区的几何基础**

"船舶领域"是本船周围应保持清空的安全领域。经典模型及本项目采用：

| 模型 | 提出者 | 形式 | 关键参数 |
|------|--------|------|----------|
| 椭圆领域 | Fujii & Tanaka (1971) | 椭圆 | 长轴 8L、短轴 3.2L（受限水域缩至 6L×1.6L），L 为船长 |
| 分扇区领域 | Goodwin (1975) | 三扇区（112.5° 分界） | 右舷 0.85 nm、船尾 0.45 nm、左舷 0.70 nm |
| 四元船舶领域 | Wang (2010) | 四半径 + 形状参数 k | 前/后/左/右四半径，支持模糊边界 |

本项目采用**分扇区（角度间隔）**思路：围绕本船按相对方位 θ 划分扇区，各扇区安全半径不同（船艏方向机动最危险、半径最大），与 COLREGS 的会遇关系（对遇/交叉/追越）相对应。

**（3）碰撞危险度 CRI（模糊综合评判）**

CRI 是 [0,1] 区间的标量，越大越危险。采用经典模糊综合评判：对 DCPA、TCPA、相对距离 D、相对方位 θ、船速比 K 五个因素分别建立隶属函数，再用层次分析法（AHP）加权合成。

- **DCPA 隶属度**（正弦过渡，最关键）：

```
u(DCPA) = 1                                                （DCPA ≤ d1）
        = 1/2 - 1/2*sin[ π/(d2-d1) * (DCPA-(d1+d2)/2) ]   （d1 < DCPA ≤ d2）
        = 0                                                （DCPA > d2）
```

其中 d1 为安全会遇距离（按相对方位 θ 分段取 0.7~1.1 nm），d2 = 2*d1。

- **TCPA 隶属度**（随 |TCPA| 减小而升高）：

```
u(TCPA) = 1                            （|TCPA| ≤ t1）
        = [(t2-|TCPA|)/(t2-t1)]^2     （t1 < |TCPA| ≤ t2）
        = 0                            （|TCPA| > t2）
```

- **合成 CRI**：

```
CRI = Σ ω_i * u_i ,  u_i ∈ [0,1]
权重 ω = [ω_DCPA, ω_TCPA, ω_D, ω_θ, ω_K]（AHP 确定）
```

**（4）风险分区可视化**：将船舶领域边界与 CRI 结合，划分三级区域（以 CRI > 0.5 作为预警阈值）：

| 分区 | 颜色 | 判据 | 系统动作 |
|------|------|------|----------|
| 低风险区 | 绿 | 目标在领域外、CRI 低 | 正常监视 |
| 警戒区 | 黄 | 目标进入领域边缘、CRI 中等 | 提示性告警 |
| 高警戒区 | 红 | 目标进入领域核心、CRI 高 | **最高级别声光告警 + 避让建议** |

> **关于"自动干预"的定位**：目标进入红色区域后，系统**自动触发最高级别告警并给出避让建议（转向方向、减速幅度）**，由驾驶员确认执行；系统**不直接操纵船舶的自动舵与主机**。该设计既保证告警的实时性与确定性，又符合"辅助决策、人为主导"的安全边界与法规要求。

**（5）统一风险框架**：无论目标是"有 AIS 的大船"还是"无 AIS 的渔船"，都送入**同一套船舶领域 + CRI 风险模型**。区别仅在数据来源——AIS 目标直接使用 AIS 数据，无 AIS 渔船则由视觉跟踪估计其航向航速后，作为"虚拟 AIS 目标"接入。

### 3.6 避碰决策与损失最小化

**（1）可避情形**：依据会遇关系（对遇 / 交叉 / 追越）与《国际海上避碰规则》（COLREGS），给出符合规则的避让建议（谁让谁、往哪转）。

**（2）不可避情形——损失最小化**：当剩余时间不足以避免碰撞时，求解一个带约束的优化问题，目标是让碰撞损失最小：

```
决策变量：舵角 δ（转向方向与幅度）、减速量 Δv、动作时机 t₀

目标函数：min  J = w₁·撞击动能(≈伤亡概率) + w₂·搁浅风险 + w₃·破舱漏油风险

约束：
  ① 航道边界（ECDIS 浅滩水深边界）——不能为避渔船把自己开上浅滩
  ② 本船机动能力——转弯率上限、减速上限（大船惯性极大）
  ③ COLREGS 合规
```

物理依据：

- **减速是第一杠杆**：碰撞破坏由动能 `E = ½mv²` 决定，速度减半、动能降为 1/4；
- **选撞击角**：斜向擦碰比正面直撞传递能量小，更易将小船"推开"而非"压碎"；
- **用船头受撞**：船首（含球鼻艏）是加强结构，船侧最薄，保护本船不破舱漏油；
- **核心目标是"保人命 + 防污染"**：渔船在万吨商船面前注定牺牲，优化对象是人命与污染，而非渔船船体。

### 3.7 输出与人机交互

- 驾驶台显示器叠加显示：本船船舶领域（绿/黄/红）、周边目标、风险等级、避让建议。
- 告警分级：绿区静默、黄区提示、红区最高级别声光告警。
- 系统**不接管**自动舵与主机，一切动作由驾驶员决策执行。

## 四、核心创新点

1. **看得见——无 AIS 小目标的融合感知**：可见光+红外多传感器融合，结合数据关联，实现对"无 AIS 渔船"这一高危盲区目标的主动发现与识别。

2. **猜得准——渔船机动的学习式预测**：用序列模型学习渔船机动模式，输出含不确定性的轨迹预测，解决传统直线外推对"会突然转向/停船"目标失效的问题。

3. **损失小——碰撞不可避免时的兜底决策**：把避碰研究从"一定能避开"延伸到"避不开怎么办"，建立减速+选角+防搁浅的损失最小化优化框架。

4. **统一风险分区框架**：分扇区船舶领域 + 碰撞危险度 CRI 的绿/黄/红分区，统一处理 AIS 目标与视觉目标，形成一套可解释、可可视化的风险表达。

## 五、项目可行性

### 5.1 技术可行性

- **检测**：小目标检测、多目标跟踪均为成熟方向，公开数据集充足（SeaShips、新加坡海事数据集、MODD2 等）。
- **轨迹预测**：序列预测（LSTM/Transformer）方法成熟，有专门的海事轨迹预测基准（如 MARIS-Forecast 数据集）。
- **风险评估**：船舶领域、DCPA/TCPA、碰撞危险度 CRI 均为经典、有文献支撑的方法，本项目在此基础上集成创新。
- **决策优化**：带约束的优化问题，可用常规数值优化方法求解。

### 5.2 数据来源方案

| 用途 | 数据来源 | 成本 |
|------|----------|------|
| 算法开发与验证（检测/预测/风险模型） | 免费公开数据：NOAA MarineCadastre、丹麦海事局 DMA、MARIS-Forecast、Piraeus 等 | 免费 |
| 渔船运动特征校准 | Global Fishing Watch 渔船 AIS 数据（提取真实航速/转向/停船统计） | 免费 |
| 伶仃航道演示背景 | 海事大学实验室数据 / 免费回放手动记录 / HiFleet 最小量购买 | 低成本 |

> 策略：**算法开发用免费外国数据（碰撞风险物理规律区域无关），演示用伶仃真实数据**，兼顾成本与真实性。

### 5.3 实施计划（初步）

| 阶段 | 内容 |
|------|------|
| 阶段一 | 搭建仿真骨架：真实轨迹回放 + 渔船状态机注入 + DCPA/TCPA 风险计算 |
| 阶段二 | 训练小目标检测模型，实现多目标跟踪与数据关联 |
| 阶段三 | 实现渔船轨迹预测（含不确定性） |
| 阶段四 | 构建分扇区船舶领域 + CRI 风险分区模型 |
| 阶段五 | 实现损失最小化决策优化 |
| 阶段六 | 集成演示，替换为伶仃航道场景，优化可视化 |

## 六、预期成果与应用前景

### 6.1 预期成果

- 一套可运行的碰撞风险预警原型系统（仿真演示 + 可视化）；
- 检测、跟踪、预测、风险评估、决策各模块的技术报告与验证结果；
